# Budget Tracker

A personal finance web application that helps users track income and expenses and better understand their spending.

## Features

- Add and manage income and expense transactions.
- Track personal finances through an easy-to-use interface.
- Use a responsive layout that adapts to different screen sizes.
- Save financial data in the browser's local storage.
- Convert currencies using an exchange-rate API.
- Import and export financial records as JSON.

## Technologies

- HTML
- CSS
- JavaScript
- JSON
- REST APIs

## Project Structure

- `src/` — HTML pages
- `scripts/` — JavaScript application logic
- `styles/` — CSS stylesheets
- `design/` — Design documents

## Running the Project

1. Clone the repository.
2. Open the project's root `index.html` file in a web browser.
